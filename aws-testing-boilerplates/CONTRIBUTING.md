# Contributing to AWS Testing Boilerplates

We welcome contributions to improve these testing boilerplates! Here's how you can help:

## How to Contribute
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/your-feature`.
3. Make your changes and commit: `git commit -m "Add your feature"`.
4. Push to your fork: `git push origin feature/your-feature`.
5. Open a Pull Request.

## Guidelines
- Ensure templates focus on testing or security.
- Include documentation for new templates.
- Test changes in a sandbox AWS account.
- Keep code simple and automated.

## Issues
- Report bugs or suggest features via GitHub Issues.
- Provide clear steps to reproduce bugs.

Thank you for contributing!
